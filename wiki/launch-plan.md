## 3. WEAKNESSES OF THE BUDGET OPTION (Tier 1 — R30–R50)

We MUST understand these before offering the budget tier:

| # | Weakness | Detail | Mitigation |
|---|---|---|---|
| W1 | **Courier kills it** | R65 courier on a R35 product = courier is ~186% of product cost. A single budget bottle shipped = guaranteed loss. | **Never ship budget alone.** Budget = in-person/hand-sell only (hawkers, social, taxi rank). Bundled with mid/premium for courier. |
| W2 | **Thin agent margin** | R30–35 profit/bottle vs R85–100 on mid. Agents may skip it for better margin. | Position as "entry + impulse" not the main earner. Combo deals (buy 1 mid, get budget at cost). |
| W3 | **Quality stigma** | Cheapest tier = "cheap perfume" perception. If budget smells bad, it drags the whole brand down. | Source the SAME quality oil, smaller size only (30ml). Never cheapen the juice. |
| W4 | **Cannibalization** | Budget buyers upgrade to mid at 2.4× price — but only if budget doesn't satisfy the need. | Budget = trial/tester. Encourage upsell ("this is the 30ml trial — the 100ml is R170"). |
| W5 | **Inventory sprawl** | 6 more SKUs = more production MOQs, more stock risk. | Keep budget to 6 fixed SKUs. No expansion until data says otherwise. |
| W6 | **Perception vs mall** | If retail R60–70 is TOO cheap, buyers suspect quality; m-scents' floor is ~R150. | Keep budget retail ≥ R60. Don't race below FFC's R40 floor. |

**Net read:** the budget tier is a **customer-acquisition + impulse tool, not a profit engine.** Its job: get a bottle in hand cheaply, create the first sale, then upsell to mid/premium. It must be **sold in person** (no courier) or **bundled**.

## 4. BEST CHANNEL — COURIER ECONOMICS DECIDES IT

### 4.1 The courier math (Courier Guy, R65 flat, free over R2,000)

| Order | Value | Courier | Courier as % of value | Viable? |
|---|:---:|:---:|:---:|---|
| 1 budget bottle (30ml) | R35 | R65 | **186%** | ❌ Absolute loss |
| 1 mid bottle (100ml) | R95 | R65 | 68% | ❌ Unsustainable |
| 3 mid bottles | R285 | R65 | 23% | ⚠️ Margin squeeze |
| 5 mid bottles | R475 | R65 | 14% | 🟡 Borderline |
| 10 mid bottles | R950 | R65 | 7% | ✅ Works |
| 20 bottles (mixed) | R2,000+ | R0 | 0% | ✅ Best (free ship) |

**Rule of thumb:** courier is sustainable when ≤10–13% of order value → **minimum viable shipped order ≈ R500 (5+ bottles).** Below that, courier destroys the margin.

### 4.2 What this means per channel

| Channel | Courier profile | Verdict |
|---|---|:---:|
| **WhatsApp Agents** | Order 10–50 bottles (R1,000–R5,000), ONE courier drop to agent, then hand-sell. | ✅ **BEST CHANNEL** |
| **Hawkers / social sellers** | Budget tier sold hand-to-hand at taxi rank / event. ZERO courier on final sale. | ✅ **Best for budget tier** |
| **Wholesalers** | Bulk R5,000+, free shipping. | ✅ Best for volume |
| **Web store (direct consumer)** | Single bottles = courier-heavy. | ⚠️ **Weakest** — needs minimum order or pickup |
| **Stores (consignment)** | We ship bulk once; store holds. | ✅ (but needs capital — Phase 2) |

### 4.3 The winning model (courier-optimal)

```
Agent orders 10+ bottles (R500+, one courier drop)  ← courier efficient
        │
        ├──▶ Sells mid/premium to customers (in person, social, events)
        │         └── no courier on final sale
        └──▶ Sells budget tier hand-to-hand (taxi rank, school, tavern)
                  └── no courier, impulse price point
```

**The agent is the courier for the last mile.** We pay courier ONCE per bulk order to the agent. The agent distributes locally for free. This is why the agent network beats a direct-to-consumer web model on economics.

### 4.4 When courier becomes unsustainable (the failure thresholds)

1. **Order value < R500** → courier > 13% of value. Require a minimum order for shipped goods (e.g., min R500 or 5 bottles).
2. **Budget tier shipped solo** → always a loss. Block solo budget shipping (system rule: budget ships only as part of a bundle or is hand-carried).
3. **Free-shipping threshold at R2,000** → works while avg agent order is >R2,000. If agents downsize orders to R500, we absorb more courier — revisit threshold.
4. **High-frequency small orders** → an agent ordering 5×/month at R500 each pays 5× R65. Incentivize consolidation (volume discount at R2,000 to cross the free-ship line).
5. **Rural/peri-urban last-mile** → Courier Guy may charge more or refuse deep rural. Use Pargo/Pudo pickup points (agent collects) for non-metro.

## 5. MARKET ENTRY SEQUENCE (using all of the above)

| Phase | Action | Channel | Courier |
|---|---|---|---|
| **0 (now)** | Validate contract manufacturer holds inventory + get landed costs per SKU | — | — |
| **1 (wk 1–4)** | Seed 20 SKUs + ladder. Recruit 50 seed agents in **Soweto + Tembisa + Mamelodi** | WhatsApp agents | Bulk drops (≥R500) |
| **2 (wk 5–8)** | Budget tier via hawkers at taxi ranks (hand-sell, no courier). Mid/premium via agents. | Hawkers + agents | Agents bulk only |
| **3 (wk 9–12)** | Open **wholesaler** tier (bulk R5,000+, free ship). Web store live with min-order R500. | Wholesalers + web | Free ship band |
| **4 (mth 4–6)** | Expand to **Eastern Cape** (Mthatha, Mdantsane, Gqeberha). First kiosk pilot (agent-run, revenue-funded). | Agents + kiosk | Bulk + local |

**Best channel overall = WhatsApp agents ordering in bulk**, with hawkers as the budget-tier hand-sell arm. Web direct-to-consumer is the weakest channel because of courier economics — keep it for discovery + agent locator, not single-bottle shipping.
